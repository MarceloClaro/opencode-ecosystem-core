# Protocolo file-first

1. Criar run com objetivo, política e budget.
2. Registrar plano e critérios de refutação.
3. Registrar passos com tempo, custo e artefato.
4. Não executar rede/LLM; entradas externas são fornecidas pelo operador.
5. Finalizar apenas com revisor humano e veredito.
6. Preservar manifesto, review e hashes.
