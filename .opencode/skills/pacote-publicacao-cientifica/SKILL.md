# Pacote de publicação científica

## Artefatos

- `AVALIACAO_EFICACIA.md` — protocolo, não resultado.
- `PILOTO_SINTETICO.md` — ensaio operacional, não eficácia.
- `PACOTE_PEER_REVIEW.md` — convite e formulário, não parecer.
- `LEDGER_AFIRMACOES.md` — status de cada claim.
- `LICENCA.md` — CC BY-NC-SA 4.0 + MIT.
- Metadados do PDF — título, autor, assunto, palavras-chave.
- `RELATORIO_DOIS.md` — 44 DOIs ativos + 5 URLs.

## Checklist

- [ ] Título e subtítulo unificados.
- [ ] Citação no padrão autor.
- [ ] Licença e créditos de fontes.
- [ ] Nenhuma chave ou dado pessoal.
- [ ] Claim ledger atualizado.
- [ ] Peer review externo (ainda pendente).
- [ ] Estudo de eficácia (ainda pendente).
- [ ] DOI/ISBN (se aplicável).

## Limites

Presença de artefato não é aprovação. Não declare 10/10, Qualis A1, peer review
ou eficácia sem evidência externa.
