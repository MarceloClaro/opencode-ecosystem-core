# Bibliografia invertida

1. Resolva o identificador (DOI/PMID/arXiv/ISBN) na fonte primária.
2. Compare o registro de volta com a entrada bibliográfica.
3. Reporte diferenças como conjuntos: `+Autor`, `−Autor`, `+ano`, `−DOI`.
4. Não use busca pelo título como verificação circular.
5. Cache com data e hash; falha de rede é `NÃO VERIFICADO`, não "referência ok".
