This archive is a printed hypertext of \textbf{84 fragments} and \textbf{216 reading paths}. Each fragment is an autonomous unit of memory or evidence. You may traverse it in four distinct ways:

\vspace{0.8em}

\noindent\textbf{1. THE LINEAR PATH (Chronological)}\\
\noindent Follow the sequence of the pages, from childhood in the Sertão (1914) to the Epilogue. This is the recommended route for a first reading: it follows the evolution of Joaquim and the propagation of the entity in temporal order.

\vspace{0.5em}

\noindent\textbf{2. THE INVESTIGATIVE PATH (Forensic)}\\
\noindent Begin with \textbf{Part 4 (Lúcia's Investigation, 2026)}. Discover the anomalies of the diary alongside the forensic psychiatrist, then return to Parts 1, 2, and 3 to reassemble the evidence like an autopsy.

\vspace{0.5em}

\noindent\textbf{3. THE HYPERTEXTUAL PATH (Free Navigation)}\\
\noindent At the end of each fragment, follow the indicator arrows (\textbf{↪ Routes}) to jump directly between the suggested pages. Each leap reflects the very fragmentation of Patient 1,260's mind. No path is a dead end: from any fragment there is a route to the Epilogue.

\vspace{0.5em}
