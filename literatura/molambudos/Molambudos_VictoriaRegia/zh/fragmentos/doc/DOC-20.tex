\noindent \textbf{附注:}

\noindent \textit{1. 第3条（埃托尔·奥利维拉医生）没有正式的取出手续。法医研究所登记簿记录有医生的姓名，但没有证人签名、主管机构盖章或书面理由。}
\noindent \textit{2. 第4条是根据米纳斯吉拉斯州公共档案馆内部通信中的间接提及复原的。原始日期和转移负责人姓名已从实体文件上被移除，只留下一个曾经有文字的空白矩形。光学分析表明，名字是被刀片刮掉的。}
\noindent 3. 第7栏留空。2026年，当物品被转移至永久保险柜时，负责填写的职员——其姓名不在文件上——口头表示“最后一行不该由他来填”。被问及原因时，他回答：\textit{“因为日记不会留在这里。”}

\noindent 4. 当被问及是否知道物品接下来会被带往何处时，该职员迟疑了一下，说：\textit{“交到正在等待的人手里。”}

\noindent \textbf{档案员结论:}
\noindent 该物品的保管链不连续。有两处未填补的文件空白，还有一条无法确认负责人的记录。该物品至少流转了47年而没有正式的踪迹登记。
\noindent 这份文书本身，就是一份关于缺失的文件。





\noindent \textit{档案员注：本部分的碎片由卢西亚·门德斯医生在2026年研究期间整理。她的笔记以斜体写在原始文件的页边。档案中最古老的文献——来自1853年——由她发现并附入案卷。}
