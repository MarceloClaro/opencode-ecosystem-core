# Imagens do Livro

Coloque aqui os arquivos de imagem utilizados no livro.

## Estrutura

```
imagens/
├── capa.png           # Imagem da capa
├── exemplo-gradcam.png # Exemplo de mapa Grad-CAM
└── figuras/
    ├── cap01/         # Figuras do Capítulo 1
    ├── cap02/         # Figuras do Capítulo 2
    ├── ...
    └── cap15/         # Figuras do Capítulo 15
```

## Formatos aceitos

- PNG (recomendado para screenshots e diagramas)
- JPG/JPEG (para fotografias)
- PDF (para gráficos vetoriais)
- EPS (para figuras acadêmicas)

## Nota

Os diretórios de figuras de cada capítulo estão vazios intencionalmente,
aguardando a inserção das imagens finais durante o processo de produção.
