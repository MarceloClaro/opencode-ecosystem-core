A geração por agente não substitui os dados observacionais porque as informações únicas obtidas durante a execução do modelo são anátenas às condições específicas da execução, não se aplicando a outros cenários semelhantes. Para reproducir uma análise, é necessário preservar o ambiente e as configurações utilizadas na execução inicial, como criar um perfil de agentes personalizado para replicar exatamente as mesmas condições.
