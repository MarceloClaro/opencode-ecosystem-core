A geração por agente não substitui dados observacionais porque cada vez que o agente for criado ou atualizado, seus conhecimentos são apenas complementados ou modificados de acordo com as instruções dadas; apenas dados explicitamente atualizados pelo usuário vão refletir esse novo conhecimento.

 Para reproduzir uma análise: você pode re-running a comando ou passagem de dados que o Hermes Agent processou anteriormente, e observar os arquivos `verded` e `memories/` produzidos para compreender suas modificações.
