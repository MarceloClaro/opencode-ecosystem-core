% Data Availability
\section*{Data Availability Statement}

The Pima Indians Diabetes Database used in this study is publicly available 
at the UCI Machine Learning Repository 
(\url{https://archive.ics.uci.edu/ml/datasets/pima+indians+diabetes}). 
The dataset was originally collected by the National Institute of Diabetes 
and Digestive and Kidney Diseases and has been widely used for benchmarking 
machine learning models. All data used in this study are freely accessible 
without restrictions. The demographic attributes (gender and ethnicity) were 
simulated for the purposes of fairness analysis, as described in the 
Methodology section. All code generated for this study is available at 
\url{https://github.com/MarceloClaro/opencode-ecosystem-core}.

% Code Availability
\section*{Code Availability}

All experimental code, including data preprocessing, model training, 
fairness analysis, and figure generation, is publicly available at 
\url{https://github.com/MarceloClaro/opencode-ecosystem-core}. 
The code was implemented in Python 3.10 using scikit-learn 1.3.0, 
pandas 2.1.0, numpy 1.25.0, and matplotlib 3.7.0. The random seed 
was fixed at 42 for reproducibility.
