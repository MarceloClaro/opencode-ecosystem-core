% Disponibilidade dos Dados
\section*{Declaração de Disponibilidade dos Dados}

O Banco de Dados de Diabetes dos Índios Pima utilizado neste estudo está 
publicamente disponível no Repositório de Aprendizado de Máquina UCI 
(\url{https://archive.ics.uci.edu/ml/datasets/pima+indians+diabetes}). 
O conjunto de dados foi originalmente coletado pelo Instituto Nacional de 
Diabetes e Doenças Digestivas e Renais e tem sido amplamente utilizado para 
benchmarking de modelos de aprendizado de máquina. Todos os dados utilizados 
neste estudo são livremente acessíveis sem restrições. Os atributos 
demográficos (gênero e etnia) foram simulados para fins de análise de 
justiça, conforme descrito na seção de Metodologia. Todo o código gerado 
para este estudo está disponível em 
\url{https://github.com/MarceloClaro/opencode-ecosystem-core}.

% Disponibilidade do Código
\section*{Disponibilidade do Código}

Todo o código experimental, incluindo pré-processamento de dados, treinamento 
de modelos, análise de justiça e geração de figuras, está publicamente 
disponível em \url{https://github.com/MarceloClaro/opencode-ecosystem-core}. 
O código foi implementado em Python 3.10 usando scikit-learn 1.3.0, 
pandas 2.1.0, numpy 1.25.0 e matplotlib 3.7.0. A semente aleatória foi 
fixada em 42 para reprodutibilidade.
