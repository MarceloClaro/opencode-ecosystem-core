# SPEC-935-R357 — Edição Trilíngue PT-BR / EN / ZH de Molambudos

**Estado:** ativa
**Autor:** marceloclaro (orquestrador) via pipeline R356 (ZH integral concluído)
**Fonte:** miolos PT (`main.tex`), EN (`en/main_en.tex`) e ZH (`zh/main_zh.tex`) — todos compilando com gate verde

## Objetivo

Gerar **um único volume trilíngue** de *Molambudos — O Diário do Paciente 1.260*,
contendo os 78 fragmentos em **Português-BR (original) → English → 简体中文**,
com aparato completo (frontmatter, navegação, mapas, epílogo, pós-leitura,
backmatter) também trilíngue.

## Decisões de design (R357)

1. **Espelho por fragmento**: cada fragmento aparece como 3 blocos consecutivos
   (PT → EN → ZH), separados por filete + etiqueta da língua. Nenhum fragmento é
   editado: reutilização integral dos 234 arquivos existentes (zero drift).
2. **Motor único**: XeLaTeX + `misc/options_zh.sty` (xeCJK + fontspec) — o PT e o
   EN passam a rodar sob XeLaTeX (EB Garamond via fontspec), requisito para o ZH.
3. **Âncoras únicas**: `\fragdef{ID}` apenas no bloco PT; as rotas `\rota{}` dos
   blocos EN/ZH resolvem para o mesmo label (mecânica idêntica ao livro atual).
4. **Nota do editor contextual**: `\let\NE` trocado por língua antes de cada
   `\input` ([N.E.] / [Ed. Note] / [编者按]).
5. **Partes**: `\partopener` com os 3 títulos (página negra + ícone).
6. **Frontmatter/backmatter trilíngues**: cada seção em 3 blocos PT→EN→ZH,
   criados combinando os textos oficiais das 3 edições (não novas traduções).
7. **Índice de fragmentos**: 78 linhas, cada uma com ID + títulos PT · EN · ZH
   (títulos extraídos dos arquivos-fonte; LUC-14 ZH usa o título impresso
   "临床自评（DSM-5-TR）").
8. **Formato**: mesmo do miolo ZH padrão (quadrado Victoria Regia), sem wrapper
   KDP (volume único ~1.200 pp. seria inviável para impressão; o artefato é
   digital/PDF de referência).
9. **Glossário**: tabela trilíngue de termos centrais (PT | EN | ZH) + seções
   históricas em 3 blocos.

## Critérios de aceitação (gate SDD)

1. `tri/main_tri.tex` compila com XeLaTeX (2 passadas): **exit 0**, **0 erros**,
   **0 referências indefinidas**, **0 missing chars**.
2. **234 inputs de fragmentos** (78 × 3 línguas) presentes; paridade de conteúdo
   garantida por reutilização direta dos arquivos (não re-traduzidos).
3. **78 `\fragdef` únicos** (labels das rotas); rotas das 3 línguas resolvidas.
4. Frontmatter trilíngue: titlepage, aviso, epígrafe, cuidado, copyright, CIP,
   nota do arquivista, como ler, TOC, nota editorial, nota histórica, glossário,
   ficha beta, backpage — todos com blocos PT/EN/ZH.
5. Backmatter trilíngue: epílogo + instrução pós-leitura + contador 1,263.
6. Navegação trilíngue: índice de 78 fragmentos com títulos nas 3 línguas +
   mapas (3 grafos) com textos trilíngues.
7. Registro do ciclo R357 no EvolutionRegistry com lições.
8. Anti-overclaim: artefato declarado como rascunho editorial (espelho das
   edições aprovadas R354/R355/R356); nenhuma alegação de validação externa.

## Riscos

- Tempo de compilação alto (~1.200 pp., XeLaTeX) — aceitável para artefato final.
- TOC automático extenso (78 entradas × aparato) — usar `\tableofcontents` com
  estilo compacto.
- Colisão de `\jobname` na raiz (como em R356): PDF `main_tri.pdf` na raiz.
