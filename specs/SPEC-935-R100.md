# SPEC-935-R100 — Livro-Core Didático: do Raio-X Técnico ao Manual Reprodutível para Leigos sem Perder Rigor

## Status
Proposta — 11/10/2026 — Orquestrador marceloclaro

## 1. Problema
O `livro-core/main.pdf` (348 p.) já é um raio-X técnico-dev-científico com
camadas didáticas (roteirodidatico, casoguiado Ana/Bruno, Nível 0 Universal
mod-18, E1–E7 para leigos mod-17, Jornada F-S-T-R mod-00b, Epílogo 12 passos
mod-15, podcasts mod-19/20). Falta, porém, a costura de **livro didático**:
(1) projeto pedagógico explícito; (2) mapa consolidado teoria→mecanismo;
(3) trilha WSL/Windows para leigo absoluto reproduzir do zero;
(4) padronização "o que é / como funciona / como refazer" em todos os capítulos.

Pergunta central: como qualquer leitor compreende o que é o Core, como ele
funciona tecnicamente e como reproduzi-lo, com teorias e artigos citados,
sem que simplificação vire overclaim?

## 2. Decisão
Transformar por **adição de 3 módulos frontais** (sem reescrever as 348 p.):
- `mod-00c-projeto-pedagogico.tex` — contrato didático: quem é Ana/Bruna/Bruno,
  objetivos por parte (Bloom lembrar→criar), 3 trilhas de leitura, como avaliar.
- `mod-21-mapa-teorias.tex` — tabela única teoria→regra do Core→o que NÃO prova,
  com os 14 DOIs já auditados + 4 âncoras novas.
- `mod-22-reproducao-wsl-leigo.tex` — do `\\wsl.localhost\Ubuntu\...` ao PDF:
  12 micro-passos com comando, saída esperada e desvio comum, para Windows+WSL.

Costura em `main.tex` (frontmatter, antes de mod-01): 00c → 21 → 22.
Nenhum módulo existente é apagado.

## 3. Critérios de aceitação (gate fail-closed)
1. `python3 livro-core/check.py` → `ok`.
2. `pdflatex main.tex` compila sem erro; `main.pdf` cresce (novas páginas) e
   sumário lista os 3 novos capítulos.
3. Cada novo módulo usa SOMENTE macros existentes (roteirodidatico, casoguiado,
   elemento, descricao, funcao, definicao, metodo, resultado, limite, aviso,
   niveis, flowch+fontecore) e `\citref` com DOI já verificado no livro
   (nenhum DOI novo sem sondagem).
4. Anti-overclaim R110: cada teoria vem com frase "inspira a regra, não
   certifica o Core"; cada cálculo rotula hipóteses; cada contagem é datada.
5. Trilha WSL reproduzível: comandos copiáveis, saídas esperadas literais,
   seção "se der errado" por passo.

## 5. Riscos e limites declarados
- Simplificação para leigos NÃO substitui spec/teste/gate; Nível 0 é porta de
  entrada, não certificação.
- Contagens (agentes, specs, LOC) são fotografias datadas do checkout.
- Execução em outra máquina pode divergir (dependências, credenciais, modelos).
- Nenhuma promessa de nota, Qualis ou aceite (revisão humana obrigatória).

## 6. Plano de verificação
`check.py` + `latexmk -pdf main.tex` + conferência manual do sumário +
sondagem DOI (só reutilizar DOIs já auditados).
