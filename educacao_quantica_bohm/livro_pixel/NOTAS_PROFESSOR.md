# Notas ao professor: uma vez por parte {#notas-professor}

> **Por que este apêndice existe.** As notas “Para o professor” eram repetidas
> em cada lauda. Elas são úteis, mas a repetição não acrescentava informação.
> Esta página conserva a orientação uma vez por parte; a lauda mantém apenas o
> limite específico do conceito.

| Parte | N0 — concreto | N1 — médio/graduação | N2 — pesquisa |

## Como usar

1. Localize a parte no rodapé da lauda (`P01`, `P02`, …).
2. Leia a coluna do nível correspondente (`N0`, `N1`, `N2`).
3. Use o limite específico da lauda como pergunta de saída.

O nível N2 não repete a instrução em cada lauda: a réplica com outra seed ou
backend é um protocolo de pesquisa, não um texto de abertura. Registre seed,
backend, data e task ID no caderno.
