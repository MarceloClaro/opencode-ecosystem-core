# Sumário navegável {#sumario}

Este sumário usa links internos e números de página gerados pelo próprio PDF.
Clique em qualquer linha para saltar. Os códigos `L`, `C`, `F` e `G` também
funcionam na busca textual.

> **Nota:** os números de página são recalculados a cada compilação. Se você
> estiver lendo uma edição impressa, use os códigos `L`, `C`, `F` e `G`; eles
> não mudam entre edições.
