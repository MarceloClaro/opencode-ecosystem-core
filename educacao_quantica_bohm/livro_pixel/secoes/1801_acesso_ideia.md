<h2 id="l-1801" class="titulo">Acesso — ideia em 60s</h2>
<div class="corpo">

<p><strong>Acesso</strong> em uma frase: Acesso é a possibilidade real de usar infraestrutura, dados e formação.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">访问</span> <em>fǎng wèn</em> <span class="tom">· tons 3-4 · leitura fang-uen</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">访问是核心概念。</span> <em>Fǎng wèn shì hé xīn gài niàn.</em> — “Acesso” é o conceito central.</span></p>

<div class="tres-passos">
<span class="rotulo">LEIA EM 3 PASSOS</span>
<p><strong>1. O que é:</strong> Acesso é a possibilidade real de usar infraestrutura, dados e formação.</p>
<p><strong>2. Como testar:</strong> Acesso formal no site não garante acesso efetivo ao hardware.</p>
<p><strong>3. O que não prova:</strong> Não há consenso moral automático; há trade-offs.</p>
</div>
