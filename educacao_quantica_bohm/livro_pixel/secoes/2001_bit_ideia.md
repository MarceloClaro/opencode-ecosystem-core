<h2 id="l-2001" class="titulo">Bit — ideia em 60s</h2>
<div class="corpo">

<p><strong>Bit</strong>: Um bit é a menor diferença que decidimos registrar: 0 ou 1.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">比特</span> <em>bǐ tè</em> <span class="tom">· tons 3-4 · leitura bi-te</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">比特是核心概念。</span> <em>Bǐ tè shì hé xīn gài niàn.</em> — “Bit” é o conceito central.</span></p>

<div class="tres-passos">
<span class="rotulo">LEIA EM 3 PASSOS</span>
<p><strong>1. O que é:</strong> Um bit é a menor diferença que decidimos registrar: 0 ou 1.</p>
<p><strong>2. Como testar:</strong> Represente 13 em binário usando cinco cartões.</p>
<p><strong>3. O que não prova:</strong> A analogia não explica probabilidade; o bit clássico é exclusivo.</p>
</div>

<p><strong>Conexão:</strong> Com 8 bits, há 256 combinações; uma letra ASCII cabe em 8 bits.</p>
<p><strong>Pergunta de pesquisa:</strong> Quando uma diferença vira informação?</p>
