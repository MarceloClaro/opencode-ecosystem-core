<h2 id="l-1115" class="titulo">Equação do guia — erro comum</h2>
<div class="corpo">

<p><strong>O erro comum:</strong> Achar que a equação é uma força newtoniana disfarçada.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">导波方程</span> <em>dǎo bō fāng chéng</em> <span class="tom">· tons 3-1-1-2 · leitura dau-bo-fang-tcheng</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">导波方程不是魔法。</span> <em>Dǎo bō fāng chéng bú shì mó fǎ.</em> — “Equação do guia” não é magia.</span></p>
<div class="dossie"><span class="rotulo-dossie">DOSSIÊ</span><p>A ficha mede “A equação de Bohm é uma releitura da equação de Schrödinger” e admite “A equação é não local para várias partículas; não é uma força clássica”. O erro está em tratar esse registro como definição de Equação do guia.</p></div><div class="exercicio"><span class="rotulo-dossie">EXERCÍCIO</span><p>Escreva um contraexemplo que separe esse registro de Equação do guia.</p></div>
