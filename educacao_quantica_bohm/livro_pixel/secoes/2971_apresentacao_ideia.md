<h2 id="l-2971" class="titulo">Apresentação — ideia em 60s</h2>
<div class="corpo">

<p><strong>Apresentação</strong>: Apresentar é tornar uma ideia compreensível para uma plateia específica.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">展示</span> <em>zhǎn shì</em> <span class="tom">· tons 3-4 · leitura djan-shi</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">展示是核心概念。</span> <em>Zhǎn shì shì hé xīn gài niàn.</em> — “Apresentação” é o conceito central.</span></p>

<div class="tres-passos">
<span class="rotulo">LEIA EM 3 PASSOS</span>
<p><strong>1. O que é:</strong> Apresentar é tornar uma ideia compreensível para uma plateia específica.</p>
<p><strong>2. Como testar:</strong> Apresentar não é ler slides; é responder a perguntas.</p>
<p><strong>3. O que não prova:</strong> O projeto não esgota o problema; escolhe um recorte.</p>
