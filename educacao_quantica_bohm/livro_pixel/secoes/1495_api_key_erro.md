<h2 id="l-1495" class="titulo">API key — erro comum</h2>
<div class="corpo">

<p><strong>O erro comum:</strong> Leia a chave de uma variável de ambiente, nunca do código.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">密钥</span> <em>mì yuè</em> <span class="tom">· tons 4-4 · leitura mi-yue</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">密钥不是魔法。</span> <em>Mì yuè bú shì mó fǎ.</em> — “API key” não é magia.</span></p>
<p><strong>Por que acontece:</strong> o cérebro procura uma imagem simples e apaga a parte matemática que não se encaixa.</p>
<p><strong>Como testar:</strong> escreva um contraexemplo em uma frase e veja se ele derruba sua explicação.</p>

</div>
<div class="rigor">
<span class="rotulo">RIGOR CIENTÍFICO</span>

<p class="prof"><strong>Para o professor:</strong> T1, T2, erro de leitura e ruído de porta são coisas distintas; não os trate como um número único.</p>
