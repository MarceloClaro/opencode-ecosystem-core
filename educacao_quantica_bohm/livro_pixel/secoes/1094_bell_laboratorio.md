<h2 id="l-1094" class="titulo">Estado de Bell — laboratório</h2>
<div class="corpo">

<p>O estado de Bell é a base do teste CHSH. Quatro configurações foram enviadas ao <strong>Guoji08</strong>, com 1024 tiros cada.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">贝尔态</span> <em>bèi ěr tài</em> <span class="tom">· tons 4-3-4 · leitura bei-er-tai</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">观察贝尔态。</span> <em>Guān chá bèi ěr tài.</em> — Observe “Estado de Bell”.</span></p>

<table class="dados">
<tr><th>Configuração</th><th>E ideal</th><th>E medido</th></tr>
<tr><td>E00</td><td>+0,707</td><td>+0,574</td></tr><tr><td>E01</td><td>+0,707</td><td>+0,576</td></tr><tr><td>E10</td><td>+0,707</td><td>+0,566</td></tr><tr><td>E11</td><td>-0,707</td><td>-0,666</td></tr>
</table>
<p class="mini">S = E00 + E01 + E10 − E11 = <strong>2,383</strong>.
Limite clássico 2; ideal quântico 2√2 ≈ 2,828. O valor observado viola o limite clássico |S| ≤ 2.
Uma execução não é prova estatística: com 1024 tiros por circuito, o erro de S
é da ordem de 0,06. <span class="fn"><strong>NOTA DE CÁLCULO.</strong><br><strong>Fórmula:</strong> E = (N₀₀+N₁₁−N₀₁−N₁₀)/N; S = E₀₀+E₀₁+E₁₀−E₁₁.<br><strong>Conta:</strong> E₀₀=588/1024=0,5742; E₀₁=590/1024=0,5762; E₁₀=580/1024=0,5664; E₁₁=−682/1024=−0,6660.<br><strong>Resultado:</strong> S = 0,5742+0,5762+0,5664+0,6660 = 2,3828.<br><em>Limite:</em> S>2 viola a desigualdade clássica; uma execução não é prova estatística definitiva.</span></p>
