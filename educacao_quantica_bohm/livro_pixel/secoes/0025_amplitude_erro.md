<h2 id="l-0025" class="titulo">Amplitude — erro comum</h2>
<div class="corpo">

<p><strong>O erro comum:</strong> Somar amplitudes como se fossem probabilidades.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">振幅</span> <em>zhèn fú</em> <span class="tom">· tons 4-2 · leitura djen-fu</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">振幅不是魔法。</span> <em>Zhèn fú bú shì mó fǎ.</em> — “Amplitude” não é magia.</span></p>
<div class="dossie"><span class="rotulo-dossie">DOSSIÊ</span><p>A ficha mede “A regra de Born transforma amplitude em probabilidade” e admite “A amplitude não é uma probabilidade; é preciso elevar ao quadrado”.</p></div><div class="exercicio"><span class="rotulo-dossie">EXERCÍCIO</span><p>Escreva um contraexemplo que separe esse registro de Amplitude.</p></div>
</div>
<div class="rigor">
<span class="rotulo">RIGOR CIENTÍFICO</span>
<p>Medir produz uma amostra; não é ler um valor escondido.</p>
