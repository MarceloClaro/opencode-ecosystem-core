<h2 id="l-1761" class="titulo">Projeto — ideia em 60s</h2>
<div class="corpo">

<p><strong>Projeto</strong> em uma frase: Um projeto articula pergunta, hipótese, experimento, evidência e limite.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">项目</span> <em>xiàng mù</em> <span class="tom">· tons 4-4 · leitura shiang-mu</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">项目是核心概念。</span> <em>Xiàng mù shì hé xīn gài niàn.</em> — “Projeto” é o conceito central.</span></p>

<div class="tres-passos">
<span class="rotulo">LEIA EM 3 PASSOS</span>
<p><strong>1. O que é:</strong> Um projeto articula pergunta, hipótese, experimento, evidência e limite.</p>
<p><strong>2. Como testar:</strong> Projeto não é relatório; precisa de decisão e teste.</p>
<p><strong>3. O que não prova:</strong> A técnica não funciona igual para todos os estudantes.</p>
</div>

<p><strong>Pare e pense:</strong> Qual é o limite do meu projeto?</p>

</div>
<div class="rigor">
<span class="rotulo">RIGOR CIENTÍFICO</span>
<p>Pedagogia é contextual. Não há método com efeito garantido para toda turma.</p>
<p class="prof"><strong>Para o professor:</strong> Nanoaula é unidade de tempo e evidência, não fragmento sem síntese.</p>
</div>
