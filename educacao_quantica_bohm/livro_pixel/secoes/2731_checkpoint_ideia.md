<h2 id="l-2731" class="titulo">Checkpoint — ideia em 60s</h2>
<div class="corpo">

<p><strong>Checkpoint</strong>: Um checkpoint é uma parada verificável antes de avançar.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">检查点</span> <em>jiǎn chá diǎn</em> <span class="tom">· tons 3-2-3 · leitura djien-tcha-dien</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">检查点是核心概念。</span> <em>Jiǎn chá diǎn shì hé xīn gài niàn.</em> — “Checkpoint” é o conceito central.</span></p>

<div class="tres-passos">
<span class="rotulo">LEIA EM 3 PASSOS</span>
<p><strong>1. O que é:</strong> Um checkpoint é uma parada verificável antes de avançar.</p>
<p><strong>2. Como testar:</strong> Checkpoint não é prova; é diagnóstico de passagem.</p>
<p><strong>3. O que não prova:</strong> A técnica não funciona igual para todos os estudantes.</p>
</div>
