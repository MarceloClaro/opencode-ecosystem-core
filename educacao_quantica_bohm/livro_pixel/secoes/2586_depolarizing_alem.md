<h2 id="l-2586" class="titulo">Depolarizing — para ir além</h2>
<div class="corpo">

<p>A fidelidade proxy mede a população ideal, não a pureza do estado.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">去极化</span> <em>qù jí huà</em> <span class="tom">· tons 4-2-4 · leitura tchyu-dji-rua</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">深入了解去极化。</span> <em>Shēn rù liǎo jiě qù jí huà.</em> — Aprofunde-se em “Depolarizing”.</span></p>
<p><strong>O que ainda não sabemos:</strong> O teste é pequeno; não generaliza para outros dados ou modelos. <span class="fn"><strong>NOTA DE CÁLCULO.</strong><br><strong>Fórmula:</strong> Depolarizing: P(1) → (1−γ)P(1) + γ/2.<br><strong>Conta:</strong> P(1)=0,967 e γ=0,05: 0,95×0,967 + 0,025 = 0,9437.<br><strong>Resultado:</strong> A margem até 0,5 cai de 0,467 para 0,444.<br><em>Limite:</em> O modelo isotrópico é uma aproximação; o ruído real não é uniforme.</span></p>
