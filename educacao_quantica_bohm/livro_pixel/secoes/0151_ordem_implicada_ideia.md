<h2 id="l-0151" class="titulo">Ordem implicada — ideia em 60s</h2>
<div class="corpo">

<p><strong>Ordem implicada</strong> em uma frase: Bohm propôs que o mundo explícito se desdobra de uma totalidade implicada.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">隐缠序</span> <em>yǐn chán xù</em> <span class="tom">· tons 3-2-4 · leitura in-tchan-shyu</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">隐缠序是核心概念。</span> <em>Yǐn chán xù shì hé xīn gài niàn.</em> — “Ordem implicada” é o conceito central.</span></p>

<div class="tres-passos">
<span class="rotulo">LEIA EM 3 PASSOS</span>
<p><strong>1. O que é:</strong> Bohm propôs que o mundo explícito se desdobra de uma totalidade implicada.</p>
<p><strong>2. Como testar:</strong> Reconstrua uma letra com 1% dos coeficientes de Fourier.</p>
<p><strong>3. O que não prova:</strong> É uma visão filosófica, não uma teoria física testável por si só.</p>
