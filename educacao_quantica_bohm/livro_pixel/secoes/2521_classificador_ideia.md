<h2 id="l-2521" class="titulo">Classificador — ideia em 60s</h2>
<div class="corpo">

<p><strong>Classificador</strong>: Um classificador mapeia dados para rótulos por meio de um modelo.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">分类器</span> <em>fēn lèi qì</em> <span class="tom">· tons 1-4-4 · leitura fen-lei-tchi</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">分类器是核心概念。</span> <em>Fēn lèi qì shì hé xīn gài niàn.</em> — “Classificador” é o conceito central.</span></p>

<div class="tres-passos">
<span class="rotulo">LEIA EM 3 PASSOS</span>
<p><strong>1. O que é:</strong> Um classificador mapeia dados para rótulos por meio de um modelo.</p>
<p><strong>2. Como testar:</strong> A peneira é uma metáfora; o modelo pode aprender vieses.</p>
<p><strong>3. O que não prova:</strong> O teste é pequeno; não generaliza para outros dados ou modelos.</p>
</div>

<p><strong>Conexão:</strong> A fidelidade proxy mede a população ideal, não a pureza do estado.</p>
