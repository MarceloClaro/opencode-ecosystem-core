<h2 id="l-2181" class="titulo">Suspensão de suposições — ideia em 60s</h2>
<div class="corpo">

<p><strong>Suspensão de suposições</strong>: Suspender é colocar uma crença entre parênteses para examiná-la.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">悬置</span> <em>xuán zhì</em> <span class="tom">· tons 2-4 · leitura shyuan-dji</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">悬置是核心概念。</span> <em>Xuán zhì shì hé xīn gài niàn.</em> — “Suspensão de suposições” é o conceito central.</span></p>

<div class="tres-passos">
<span class="rotulo">LEIA EM 3 PASSOS</span>
<p><strong>1. O que é:</strong> Suspender é colocar uma crença entre parênteses para examiná-la.</p>
<p><strong>2. Como testar:</strong> Escreva uma suposição e liste o que ela exclui.</p>
<p><strong>3. O que não prova:</strong> Suspender não é abandonar; é ganhar distância para observar.</p>
</div>

<p><strong>Conexão:</strong> A suspensão é uma prática, não uma prova lógica.</p>
<p><strong>Pergunta de pesquisa:</strong> O que eu estou supondo agora?</p>
