<h2 id="l-2076" class="titulo">Interferência — para ir além</h2>
<div class="corpo">

<p>O experimento de dupla fenda é a demonstração clássica.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">干涉</span> <em>gān shè</em> <span class="tom">· tons 1-4 · leitura gan-she</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">深入了解干涉。</span> <em>Shēn rù liǎo jiě gān shè.</em> — Aprofunde-se em “Interferência”.</span></p>
<p><strong>O que ainda não sabemos:</strong> A amplitude quântica não é uma vibração material.</p>
<p>Procure um artigo que tente responder e anote o desenho experimental. <span class="fn"><strong>NOTA DE CÁLCULO.</strong><br><strong>Fórmula:</strong> A = (1/√2)(1 + e^{iφ}); P = |A|² = cos²(φ/2).<br><strong>Conta:</strong> φ = π → cos²(π/2) = 0. φ = 0 → cos²(0) = 1.<br><strong>Resultado:</strong> Em φ = π, as duas amplitudes se cancelam e P = 0.<br><em>Limite:</em> A interferência exige coerência; ruído de fase destrói o cancelamento.</span></p>
