<h2 id="l-0021" class="titulo">Amplitude — ideia em 60s</h2>
<div class="corpo">

<p><strong>Amplitude</strong> em uma frase: Amplitude é o número que dá peso a cada estado de base.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">振幅</span> <em>zhèn fú</em> <span class="tom">· tons 4-2 · leitura djen-fu</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">振幅是核心概念。</span> <em>Zhèn fú shì hé xīn gài niàn.</em> — “Amplitude” é o conceito central.</span></p>

<div class="tres-passos">
<span class="rotulo">LEIA EM 3 PASSOS</span>
<p><strong>1. O que é:</strong> Amplitude é o número que dá peso a cada estado de base.</p>
<p><strong>2. Como testar:</strong> Use uma barra de 0 a 1 para representar α e β.</p>
<p><strong>3. O que não prova:</strong> A amplitude não é uma probabilidade; é preciso elevar ao quadrado.</p>
</div>
