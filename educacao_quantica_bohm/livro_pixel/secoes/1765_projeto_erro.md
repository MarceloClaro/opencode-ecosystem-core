<h2 id="l-1765" class="titulo">Projeto — erro comum</h2>
<div class="corpo">

<p><strong>O erro comum:</strong> Preencha o cartão de projeto em cinco campos.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">项目</span> <em>xiàng mù</em> <span class="tom">· tons 4-4 · leitura shiang-mu</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">项目不是魔法。</span> <em>Xiàng mù bú shì mó fǎ.</em> — “Projeto” não é magia.</span></p>
