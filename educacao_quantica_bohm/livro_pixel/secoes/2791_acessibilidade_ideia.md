<h2 id="l-2791" class="titulo">Acessibilidade — ideia em 60s</h2>
<div class="corpo">

<p><strong>Acessibilidade</strong>: Acessibilidade é remover barreiras para que todos possam participar.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">无障碍</span> <em>wú zhàng ài</em> <span class="tom">· tons 2-4-4 · leitura u-djang-ai</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">无障碍是核心概念。</span> <em>Wú zhàng ài shì hé xīn gài niàn.</em> — “Acessibilidade” é o conceito central.</span></p>

<div class="tres-passos">
<span class="rotulo">LEIA EM 3 PASSOS</span>
<p><strong>1. O que é:</strong> Acessibilidade é remover barreiras para que todos possam participar.</p>
<p><strong>2. Como testar:</strong> Acessibilidade não é um extra; é condição de participação.</p>
<p><strong>3. O que não prova:</strong> A técnica não funciona igual para todos os estudantes.</p>
</div>
