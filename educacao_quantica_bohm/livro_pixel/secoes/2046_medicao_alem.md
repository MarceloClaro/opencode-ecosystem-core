<h2 id="l-2046" class="titulo">Medição — para ir além</h2>
<div class="corpo">

<p>O 'colapso' é um nome para a atualização do estado após a medição.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">测量</span> <em>cè liáng</em> <span class="tom">· tons 4-2 · leitura tse-liang</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">深入了解测量。</span> <em>Shēn rù liǎo jiě cè liáng.</em> — Aprofunde-se em “Medição”.</span></p>
<p><strong>O que ainda não sabemos:</strong> A caixa pode já ter um valor; o qubit não é assim. <span class="fn"><strong>NOTA DE CÁLCULO.</strong><br><strong>Fórmula:</strong> Para H|0⟩ = (|0⟩+|1⟩)/√2, P(0) = P(1) = 1/2.<br><strong>Conta:</strong> Em 1024 tiros, o esperado é 512; o desvio padrão é √(1024×0,5×0,5) = 16.<br><strong>Resultado:</strong> Uma contagem típica fica em 512 ± 32 (dois desvios).<br><em>Limite:</em> Cada tiro exige preparar o estado de novo; medir o mesmo qubit repetidamente não dá a mesma estatística.</span></p>
