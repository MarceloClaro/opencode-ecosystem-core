<h2 id="l-2171" class="titulo">Diálogo — ideia em 60s</h2>
<div class="corpo">

<p><strong>Diálogo</strong>: Diálogo é investigação coletiva de suposições, não debate para vencer.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">对话</span> <em>duì huà</em> <span class="tom">· tons 4-4 · leitura duei-rua</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">对话是核心概念。</span> <em>Duì huà shì hé xīn gài niàn.</em> — “Diálogo” é o conceito central.</span></p>

<div class="tres-passos">
<span class="rotulo">LEIA EM 3 PASSOS</span>
<p><strong>1. O que é:</strong> Diálogo é investigação coletiva de suposições, não debate para vencer.</p>
<p><strong>2. Como testar:</strong> Faça uma roda de 15 minutos com uma pergunta aberta.</p>
<p><strong>3. O que não prova:</strong> Diálogo não é terapia, assembleia ou busca obrigatória de consenso.</p>
</div>
