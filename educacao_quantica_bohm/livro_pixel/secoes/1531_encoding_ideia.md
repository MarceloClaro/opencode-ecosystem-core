<h2 id="l-1531" class="titulo">Encoding — ideia em 60s</h2>
<div class="corpo">

<p><strong>Encoding</strong> em uma frase: Encoding é a forma de colocar dados clássicos em um circuito quântico.</p>
<p class="ponte"><strong>PONTE SONORA · 中文</strong> <span class="termo"><strong>Termo:</strong> <span class="hanzi">编码</span> <em>biān mǎ</em> <span class="tom">· tons 1-3 · leitura bien-ma</span>.</span> <span class="frase"><strong>Microfrase:</strong> <span class="hanzi">编码是核心概念。</span> <em>Biān mǎ shì hé xīn gài niàn.</em> — “Encoding” é o conceito central.</span></p>

<div class="tres-passos">
<span class="rotulo">LEIA EM 3 PASSOS</span>
<p><strong>1. O que é:</strong> Encoding é a forma de colocar dados clássicos em um circuito quântico.</p>
<p><strong>2. Como testar:</strong> Um encoding pode perder informação ou criar correlações artificiais.</p>
<p><strong>3. O que não prova:</strong> O teste é pequeno; não generaliza para outros dados ou modelos.</p>
</div>
