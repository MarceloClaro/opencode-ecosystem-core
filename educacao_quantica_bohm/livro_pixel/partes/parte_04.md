## O que você vai encontrar

- **PennyLane** — [L0301](#l-0301){.ref} — PennyLane é uma biblioteca de circuitos quânticos diferenciáveis.
- **Cirq** — [L0311](#l-0311){.ref} — Cirq é uma biblioteca do Google baseada em linhas de qubits.
- **Qiskit** — [L0321](#l-0321){.ref} — Qiskit é a biblioteca da IBM para circuitos, estados e visualização.
- **QNode** — [L0331](#l-0331){.ref} — Um QNode é uma função quântica que retorna uma medição.
- **Cirq Circuit** — [L0341](#l-0341){.ref} — Um Circuit do Cirq é uma sequência de momentos e operações.
- **QuantumCircuit** — [L0351](#l-0351){.ref} — QuantumCircuit é a estrutura do Qiskit para portas e medições.
- **Statevector** — [L0361](#l-0361){.ref} — Statevector é o vetor de amplitudes de um sistema quântico.
- **Esfera de Bloch** — [L0371](#l-0371){.ref} — A esfera de Bloch representa o estado de um único qubit.
- **Amostragem** — [L0381](#l-0381){.ref} — Amostrar é repetir preparo e medição para estimar probabilidades.
- **gjq-client** — [L0391](#l-0391){.ref} — gjq-client é o cliente Python da plataforma quântica Guoji/Tiangong.
