**Pergunta, evidência, limite.** Dez conceitos, dez lentes cada: cem laudas para explorar em sete minutos por vez.

## O que você vai encontrar

- **Pergunta** — [L0901](#l-0901){.ref} — Uma boa pergunta é delimitada, investigável e ligada a uma decisão.
- **Hipótese** — [L0911](#l-0911){.ref} — Uma hipótese é uma explicação testável, não uma opinião.
- **Evidência** — [L0921](#l-0921){.ref} — Evidência é um dado ou observação que sustenta ou enfraquece uma afirmação.
- **Limite** — [L0931](#l-0931){.ref} — Limite é o que o modelo, o experimento ou a analogia não alcança.
- **Replicação** — [L0941](#l-0941){.ref} — Replicar é repetir um experimento com registros e condições explícitas.
- **Narrativa** — [L0951](#l-0951){.ref} — Narrativa organiza fatos em uma sequência com sentido.
- **Visualização** — [L0961](#l-0961){.ref} — Visualização codifica dados em posição, cor e forma.
- **Apresentação** — [L0971](#l-0971){.ref} — Apresentar é tornar uma ideia compreensível para uma plateia específica.
- **Portfólio** — [L0981](#l-0981){.ref} — Portfólio é uma coleção organizada de evidências de aprendizagem.
- **Próximo passo** — [L0991](#l-0991){.ref} — Próximo passo é a menor ação concreta que reduz incerteza.

## Nano-trilha
