<h2 id="f-034" class="titulo">QNode — o que a evidência mostra</h2>
<div class="corpo">
<p><strong>Em uma frase:</strong> Um QNode é uma função quântica que retorna uma medição.</p>
<p><strong>Fonte primária:</strong> QISKIT DEVELOPMENT TEAM. <em>Qiskit: An Open-Source Framework for Quantum Computing</em>. Zenodo, 2024. DOI: <a href="https://doi.org/10.5281/zenodo.2573505">10.5281/zenodo.2573505</a>. <span class="mini">(DOI verificado via DataCite em 2026-11-07)</span></p>
<p><strong>O que foi medido:</strong> QNodes podem ser diferenciados e otimizados.</p>
<p><strong>O que não prova:</strong> O QNode não é o hardware; é a descrição executável.</p>
<p><strong>Prática:</strong> Crie um QNode que retorne qml.probs.</p>

<div class="resultado">
